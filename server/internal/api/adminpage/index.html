Register a security key

This key will be able to sign in here and create new vaults. It cannot open any vault: that takes the vault keys, which live only on your devices.

Your browser will ask you to touch or tap the key.

Sign in

Touch your security key to sign in. The session lasts fifteen minutes.

Create a new vault

A create link lets one device make one new vault and become its first member. It lasts an hour and works once. Scan the QR with the new device's camera, or tap Open in Obsidian on this device.
